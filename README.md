# Discord Music Bot Linker Auth 隱私權政策

最後更新日期：2026 年 8 月 8 日

## 一、政策適用範圍

本隱私權政策適用於 Chrome 擴充功能「Discord Music Bot Linker Auth」（以下稱「本擴充功能」）。

本擴充功能的用途，是讓使用者將 YouTube、SoundCloud 或 Bilibili 的影音網址，傳送至使用者自行架設並授權的 Discord Music Bot。

本擴充功能開發者不提供中央播放伺服器，也不會將使用者的授權資料或播放網址傳送至開發者控制的伺服器。使用者必須自行選擇及管理要連線的 Discord Music Bot 主機。

## 二、處理的資料

為了提供授權及播放功能，本擴充功能可能處理以下資料：

1. Discord 識別資料  
   包括 Discord 使用者 ID、Discord 伺服器 ID，以及由 Discord 顯示名稱產生的裝置名稱。

2. 授權資料  
   包括 Discord Bot 產生的一次性授權碼、限時裝置 Token、授權識別碼及授權到期時間。

3. Bot 連線資料  
   包括使用者貼上的授權連結，以及使用者自行指定的 Discord Music Bot HTTPS 網址。

4. 影音網址  
   包括使用者主動按下播放按鈕時的目前分頁網址，或使用者透過右鍵選單主動選取的超連結。

5. 連線資訊  
   使用者自行架設的 Bot 主機或其 Cloudflare Tunnel 服務可能接收連線 IP 位址。Bot 可能暫時使用 IP 位址限制授權兌換次數及防止濫用，但不會將 IP 位址寫入持久化的授權資料檔案。

本擴充功能不會讀取完整瀏覽紀錄，不會持續監控使用者瀏覽的網頁，也不會讀取網頁中的密碼、表單內容、電子郵件、私人訊息、付款資料或健康資料。

## 三、資料使用目的

上述資料僅用於以下用途：

- 兌換 Discord Bot 產生的一次性授權。
- 保存使用者的限時裝置授權。
- 辨識獲得授權的 Discord 使用者及伺服器。
- 將使用者主動選擇的影音網址傳送至其指定的 Discord Music Bot。
- 將歌曲加入 Discord 語音頻道的播放佇列。
- 驗證授權是否有效、到期或已被撤銷。
- 限制過於頻繁的請求及防止授權碼遭到猜測或濫用。
- 顯示裝置名稱及授權到期時間。

這些資料不會用於廣告、使用者追蹤、行銷、信用評分或任何與本擴充功能主要用途無關的目的。

## 四、資料保存方式

本擴充功能會使用 Chrome 提供的本機儲存空間，保存以下資料：

- 使用者指定的 Bot 網址。
- 限時裝置 Token。
- 授權識別碼。
- Discord 使用者及伺服器識別碼。
- 裝置名稱。
- 授權到期時間。

這些資料只供本擴充功能維持授權及播放功能使用。

當授權到期、被 Bot 撤銷，或 Bot 回覆授權無效時，本擴充功能會清除本機授權資料。使用者也可以移除本擴充功能，以刪除 Chrome 保存的本機資料。

一次性授權碼只能成功使用一次，並會在指定時間後失效。未兌換的一次性授權碼只保存在 Bot 的記憶體中，Bot 重新啟動後即失效。

已兌換授權由使用者自行架設的 Bot 保存。Bot 只保存裝置 Token 的雜湊值，不保存可直接使用的原始 Token。到期或撤銷的授權紀錄可能在有限期間內保留，以供裝置管理及防止編號重複，之後由 Bot 清理。

連線 IP 僅可由使用者自行架設的 Bot 暫時保存在記憶體中，用於請求次數限制，不會寫入持久化授權資料檔案。

## 五、資料傳送及分享

本擴充功能不會出售、出租或提供使用者資料給廣告商或資料仲介商。

為了完成使用者要求的功能，資料可能傳送至以下服務：

1. 使用者自行指定的 Discord Music Bot  
   接收授權碼、裝置 Token及使用者主動選擇的影音網址。

2. Discord  
   Bot 使用 Discord 提供的服務辨識使用者、伺服器及語音頻道，並執行播放指令。

3. Cloudflare Tunnel  
   如果 Bot 管理者使用 Cloudflare Tunnel，擴充功能與 Bot 之間的 HTTPS 連線可能經過 Cloudflare。Cloudflare 可能依其隱私權政策處理必要的連線及安全性資料。

4. 影音平台  
   使用者要求播放內容時，使用者自行架設的 Bot 可能向 YouTube、SoundCloud 或 Bilibili 取得使用者指定的影音內容。相關平台可能依各自的隱私權政策處理連線資料。

本擴充功能開發者不會接收或保存上述傳送至使用者自架 Bot 的資料。使用者自行架設的 Bot 及其主機環境由該 Bot 管理者負責管理。

## 六、資料安全

本擴充功能只允許使用 HTTPS 與使用者指定的 Bot 主機交換授權及播放資料。

裝置 Token 只會傳送至授權來源相同的 Bot 主機，不會附加在網址中，也不會公開顯示。

本擴充功能不會下載或執行遠端 JavaScript 或 WebAssembly。所有可執行程式碼均包含在擴充功能套件中。

雖然我們採取合理的安全措施，但任何網路傳輸或儲存方式都無法保證絕對安全。使用者應妥善保管一次性授權連結及裝置 Token，並只連線至自己信任的 Bot 主機。

## 七、使用者的控制權

使用者可以：

- 選擇是否授予特定 Bot HTTPS 網址的連線權限。
- 不使用或不兌換 Discord 產生的授權連結。
- 在 Discord 使用 `/my-access` 查看及撤銷自己的裝置授權。
- 請 Bot 管理者透過本機管理後台撤銷授權。
- 等待授權自動到期。
- 移除本擴充功能，以刪除 Chrome 本機保存的資料。
- 聯絡 Bot 管理者，要求處理該自架 Bot 保存的授權紀錄。

## 八、兒童隱私

本擴充功能不會刻意收集兒童的個人資料。使用者使用 Discord、YouTube、SoundCloud、Bilibili 或 Cloudflare 服務時，仍須遵守各服務的年齡限制及使用條款。

## 九、政策變更

如果本擴充功能的資料處理方式發生變更，本隱私權政策也會相應更新。更新後的政策會公布於相同網址，並修改頁面上方的最後更新日期。

如果變更涉及新的資料類型或新的使用目的，將依 Chrome 線上應用程式商店政策提供必要的說明及同意流程。
